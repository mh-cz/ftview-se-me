# ftview-se-me
FactoryTalk View SE edition to ME edition XML screen converter 

Open SE -> Export screens as XML -> Convert -> Open ME -> Import screens as XML

### Note
- Heavily vibecoded and made in a rush.  
- XML files do not contain images. You gotta import them manually after.  
- This will not produce a 1:1 screen copy. It transfers shapes, buttons, labels, input fields, object groups etc but ME compared to SE is incredibly dumb and limited so a lot of functionality gets simplified/stripped down.    
- It has a reverse-engineered functionality to convert RSView32/SE ActiveX multistate indicator object to a regular ME multistate indicator.
