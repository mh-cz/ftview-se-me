# ftview-se-me
FactoryTalk View SE edition to ME edition XML screen converter 

Open SE -> Export screens as XML -> Convert -> Open ME -> Import screens as XML

### Note
This will not produce a 1:1 copy. ME compared to SE is incredibly dumb and you should move from SE to ME only if absolutely necessary. ME has no VBA, no proper macros, buttons have only one action attached to them, no derived tags and only one log.
