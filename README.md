# ftview-se-me
FactoryTalk View SE edition to ME edition XML screen converter 

Open SE -> Export screens as XML -> Convert -> Open ME -> Import screens as XML

### Note
Heavily vibecoded.
This will not produce a 1:1 copy. ME compared to SE is incredibly dumb and you should move from SE to ME only if absolutely necessary.
It converts the RSV32/SE multistate indicator activex object (reverse-engineered) to a regular ME multistate indicator
