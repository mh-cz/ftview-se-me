# ftview-se-me
FactoryTalk View SE edition to ME edition XML screen converter 

Open SE -> Export screens as XML -> Convert -> Open ME -> Import screens as XML

### Note
Heavily vibecoded.  
XML files do not contain images.  
This will not produce a 1:1 screen copy. It attempt to transfer shapes, buttons, labels, input fields, object groups etc but ME compared to SE is incredibly dumb and limited.    
It has a functionality to convert RSView32/SE ActiveX multistate indicator object (reverse-engineered) to a regular ME multistate indicator.
